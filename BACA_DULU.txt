TROUBLESHOOTING:
----------------
1. Error "can't be reached"
   → Pastikan WAMP running (icon hijau)
   → Test: http://localhost/ (harus muncul halaman WAMP)

2. Error "404 Not Found"
   → Pastikan URL pakai /public/ di akhir
   → Benar: localhost/kuliah_ci4/public/

3. Tidak bisa login
   → Import ulang database_lengkap.sql
   → Atau jalankan fix_password.sql

4. Database error
   → Pastikan MySQL running
   → Cek .env sudah benar
   → Test: localhost/kuliah_ci4/test_koneksi.php
